01 / About

Practical engineering,
curious by nature.

I enjoy understanding how things work, then turning that understanding into useful, maintainable software.

My public work spans multiple layers of software: C# desktop utilities, Go backend applications, Python integrations, C++ experiments, and web-based tools. I value clear structure, reliability, and learning through building.

Alongside software projects, I'm developing a PCB solder-paste inspection (SPI) system that brings together machine vision, motion control, lighting, and embedded hardware. It is an ongoing engineering project, not a finished product.
